# Version Roadmap

## v0.1 — Source of Truth

### Objetivo:

"Sempre saber exatamente onde estou."

### Entrega:

 - Estado da transição
 - Próximos passos
 - Histórico
 - Relatório semanal
 - Priorização

## v0.2 — Automation Engine

### Objetivo:

"Parar de atualizar tudo manualmente."

### Entram:

 - GitHub Actions
 - Notion API
 - Python
 - Geração automática de relatório
 - Changelog automático

## v0.3 — Career Intelligence

### Objetivo:

"Começar a pensar."

### Entram:

 - análise de prioridades
 - identificação de gargalos
 - risco de atraso
 - Sugestão de próximos passos
 - Detecção de inconsistências

## v0.4 — Knowledge Engine

### Entram:

 - RAG
 - embeddings
 - vector database
 - leitura do GitHub
 - leitura do currículo
 - leitura das publicações

Agora ele passa a responder perguntas como:

"Já escrevi algo parecido?"

## v0.5 — ContentOps

Entram:

 - Geração de ideias
 - Calendário editorial
 - Revisão
 - Score de qualidade
 - Sugestões de imagens

## v0.6 — JobOps

Entram:

 - vagas
 - ATS
 - comparação currículo x vaga
 - score de aderência
 - acompanhamento de candidaturas
